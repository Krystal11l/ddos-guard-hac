# 🖥️ Adaptive System Analyzer

Инструмент для **мониторинга нагрузки системы в реальном времени** с выводом советов в терминал и во всплывающие окна.
Подходит для демонстрации работы ресурсов ПК и для тестирования производительности.

---

## 📊 Что умеет

Утилита отслеживает:

* **CPU**

  * загрузку процессора
  * температуру процессора (⚠️ предупреждение при ≥90°C)
* **RAM**

  * процент использования оперативной памяти (⚠️ предупреждение при ≥85%)
* **Диск**

  * заполненность диска
  * время отклика диска (⚠️ предупреждение при ≥500 мс → совет замены диска)
* **Сеть**

  * загрузку сети относительно максимальной пропускной способности
* **SSD-контроллер**

  * температуру контроллера (⚠️ предупреждение при ≥90°C → совет снизить нагрузку)

Все советы показываются как в терминале, так и в отдельном **диалоговом окне** (Tkinter).

---

## 💡 Примеры советов

* 🔥 «Процессор перегревается! Очистите кулер от пыли или улучшите охлаждение.»
* ⚠️ «Оперативная память почти заполнена. Закройте тяжёлые программы или увеличьте объём RAM.»
* 🐢 «Диск отвечает слишком медленно. Сделайте резервное копирование и подумайте о замене.»
* 📡 «Сеть перегружена. Проверьте активные загрузки или ограничьте скорость фоновых процессов.»
* 💾 «SSD перегревается! Снизьте нагрузку и обеспечьте охлаждение корпуса.»

## ⚙️ Установка

```bash
git clone https://github.com/<username>/<repo>.git
cd <repo>
pip install -r requirements.txt
```

Минимальные зависимости:

* `psutil`
* `tkinter` (идёт в стандартной библиотеке Python)

---

## ▶️ Запуск

```bash
python3 analyzer.py
```

Для стресс-тестирования (нагрузчика):

```bash
python3 stressor.py --duration 60 --target-percent 70
```
