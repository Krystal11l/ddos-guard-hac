# 🖥️ Adaptive System Analyzer

Инструмент для **мониторинга нагрузки системы в реальном времени** с выводом советов в терминал и в всплывающие окна.
Подходит для демонстрации работы ресурсов ПК и для тестирования производительности.

---

## 📊 Что умеет

Утилита отслеживает:

* **CPU**

  * загрузку процессора
  * температуру процессора
* **RAM**

  * процент использования оперативной памяти
* **Диск**

  * заполненность диска
  * время отклика диска
* **Сеть**

  * загрузку сети относительно максимальной пропускной способности
* **SSD-контроллер**

  * температуру контроллера

Все советы показываются как в терминале, так и в отдельном **диалоговом окне** (Tkinter).

---

## 💡 Примеры советов, в зависимости от вывода:

* 🔥 «Высокая загрузка CPU. СОВЕТ: закройте тяжёлые приложения.»
* ⚠️ «Высокая загрузка RAM. СОВЕТ: закройте ненужные приложения или очистите кэш, чтобы снизить нагрузку.»
* 🐢 «Время отклика диска x мс. Совет: возможно, диск требует замены.»
* 📡 «Сеть сильно нагружена. Проверьте, не загружается ли что-то в фоне (обновления, торрент-клиенты, облачные сервисы).»
* 💾 «Перегрев SSD. СОВЕТ: снизьте нагрузку.»

## ⚙️ Установка

```bash
git clone https://github.com/<username>/<repo>.git
cd <repo>
pip install -r requirements.txt
```

Минимальные зависимости:

* `psutil`
* `tkinter` (идёт в стандартной библиотеке Python)

---

## ▶️ Запуск

```bash
python3 analyzer.py
```

Для стресс-тестирования (нагрузчика):

```bash
python3 stressor.py --duration 60 --target-percent 70
```
